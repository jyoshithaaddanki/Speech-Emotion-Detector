🎙️ Speech Emotion Detector

## 📌 Project Description

Speech Emotion Detector is a simple Python project that analyzes audio signals and demonstrates emotion detection using **MFCC (Mel-Frequency Cepstral Coefficients)** features.

The project automatically creates a sample audio file, extracts audio features, and displays the detected emotion along with an MFCC visualization.

## 🛠️ Technologies Used

* Python
* Google Colab
* Librosa
* NumPy
* Matplotlib
* SciPy

## ✨ Features

* Automatically generates a sample audio file
* Extracts MFCC audio features
* Analyzes speech characteristics
* Displays a predicted emotion
* Shows MFCC feature visualization
* No audio upload required
* Beginner-friendly implementation

## 😊 Supported Emotions

The demonstration can display:

* 😊 Happy
* 😢 Sad
* 😐 Neutral

## ▶️ How to Run

1. Open **Google Colab**.
2. Create a new notebook.
3. Copy the project code into a cell.
4. Run the code.
5. The program automatically creates a sample audio file.
6. The audio features are extracted.
7. View the detected emotion and MFCC graph.

## 📊 Sample Output

```text
🎙️ SPEECH EMOTION DETECTOR
==========================

Sample audio created successfully!
File: sample_emotion.wav

===== EMOTION RESULT =====
Detected Emotion: Happy 😊
MFCC Average: 12.45
```

The program also displays an **MFCC feature graph** for the generated audio.
